# Code of conduct

We want QEYRO FI monitor to be a place where people can do careful technical work without friction.

## Expected behaviour

- Be respectful. Disagree with ideas, not with people.
- Give specific, actionable feedback. Assume good faith.
- Credit other people's work.
- Keep security discussions private until a fix is out (see SECURITY.md).

## Unacceptable behaviour

- Harassment, insults, or discriminatory language.
- Publishing someone else's private information.
- Sustained disruption of discussions or reviews.

## Enforcement

Maintainers may edit or remove comments, close issues, or block accounts that break these rules.
Report problems to the maintainers of qeyro-fi-monitor through a private GitHub security advisory ( https://github.com/qeyro-fi/qeyro-fi-monitor/security/advisories/new ) or by email to the address listed on the qeyro-fi organisation profile.
